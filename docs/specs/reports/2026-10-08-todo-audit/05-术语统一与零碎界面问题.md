# 05 · 术语统一与零碎界面问题合集

## 背景

产品经过多轮迭代，同一批概念在不同界面里叫过不同的名字；另外有几个一次性的小界面缺陷。这些单个都不值得立项，攒成一批清掉。

## 现状（2026-10-08 核验）

来自 2026 年 9 月 18 日评测、至今未动的项：

1. **同一对象三种叫法**：「对话 / 会话 / 任务」在不同界面混用——比如「重命名任务」「归档任务」按钮旁边是「新建对话」，搜索界面又叫「搜索会话」。用户需要自己脑补这是同一个东西。
2. **模式菜单中英混排**：切换模式的菜单里「计划 / Swarm / Collaboration / 目标」中英文混杂（Swarm、Collaboration 未翻译或约定为保留英文，但混排没有统一规则）。
3. **空菜单项**：工作区分组的「选项」菜单里有一个没有任何文字的菜单项（读屏软件和肉眼都看到一条空白行）。
4. **外观选项命名怪异**：首次启动的偏好设置里，英文界面的明暗选项叫「Moon Bright / Moon Dark」（月亮亮面/月亮暗面），英文语义下显得别扭。

以上除第 1、2 项属于「约定后批量替换」外，第 3、4 项都是单点小改。评测后无相关修复提交。

## 问题与影响

- 术语不统一直接抬高学习成本：新用户要建立「这三个词是一回事」的映射。
- 空菜单项是可访问性缺陷（读屏软件读到一条无名目），也影响观感。
- 「Moon Bright」这类命名让人摸不着头脑，与产品的专业气质不符。

## 期待的最终形态

- 制定一份简短的**界面用语表**（比如：对用户一律称「会话」；确认保留英文的词列出白名单，如产品专名）。
- 按用语表全量替换界面文案。
- 空菜单项找到产生原因并消除；明暗选项命名改为通用的 Light / Dark（中文「浅色 / 深色」）。

## 大致要做的事

1. 先定用语表（这是唯一需要决策的点——主要是「会话 vs 对话 vs 任务」选哪个，建议「会话」，与搜索界面现状一致，改动面最小）。
2. 扫描全部界面词条，按表替换（注意与报告 02 的品牌扫描可以同批执行，扫描工具复用）。
3. 修空菜单项（先定位：大概率是某条菜单项缺少文案绑定）。
4. 明暗选项改名，中英词条同步。

## 规模与风险

小。全部是文案层改动。唯一风险是用语表的决策返工——所以表要先评审再动手。
