# 历史读回 — 架构设计

> 状态：v1 提案基线 · 2026-09-10 · 含 ADR-001~003 ·
> 本文描述历史读回域的**终态技术设计**（机制、数据流、接口形状）；动机只保留抽象问题陈述，现状证据与代码事实见 [history-readback-context.md](history-readback-context.md)，需求见 [history-readback-requirements.md](history-readback-requirements.md)。
> 提案性质说明（同需求文档）：本域为 rust-first 设计提案，非既有能力基线；编号地基（压缩域 ADR-007）作为前提引用，不在本文重述其决策。

## 1. 概念与分层

本域由五个角色组成，全部**只读消费**既有产物：

| 角色 | 职责 |
|---|---|
| **会话日志（wire journal）** | 唯一真相——读回与检索的全部数据源（会话持久化域所有）；本域零新增事实源 |
| **编号地基**（压缩域 ADR-007 产物） | 条目编号、替换区间、丢弃清单——本域的寻址坐标系，只消费 |
| **读回服务（readback service）** | 按编号从日志投影取原文（含 live 会话与已折叠段） |
| **卡片装配（card assembler）** | 目录卡片/现状卡的生成与维护（从区间标注派生段结构） |
| **检索服务（search service）** | 关键词检索（索引形态为开放项 3） |

核心不变量：

1. **只读消费**——本域对会话日志与压缩产物零写入（唯一例外：工具结果与卡片作为正常对话内容随常规记录通道落日志）。
2. **读回结果是普通工具结果**——落位当轮对话末尾，不重排历史、不触碰既有请求前缀（缓存零失效，NFR-R1）。
3. **寻址唯一坐标系 = 会话累计条目编号**（ADR-007）——本域不引入第二套坐标，不做任何重编号。

## 2. 工具面

### 2.1 读回工具

- **参数**：编号区间（闭区间 `from`/`to`，即 `entry_seq`，会话累计编号，ADR-007 定义）；可选分页游标与单次上限（NFR-R4）。
- **返回**：区间内逐条原文（编号、角色、内容）；头部说明本区间内命中的"不可找回"编号（对应压缩域 `droppedEntrySeqs` 清单）与未读余量；编号越界时返回有效范围。
- **寻址语义**：区间为闭区间；编号由压缩域分配且跨压缩稳定，本域不做换算。

### 2.2 搜索工具

- **参数**：关键词（字面匹配，P-E1 提案口径——不做语义检索）；可选结果上限与分页游标；范围（本会话；跨会话形态为开放项 2，裁决前不实现）。
- **返回**：匹配条目的编号 + 摘要行 + 所属段落指引（与目录卡片的段落结构同源），据此可直接发起读回。

### 2.3 结果落位（ADR-002）

- 读回/搜索结果作为 T4 工具结果（工具调用域）落在**当轮对话末尾**；对既有请求前缀零扰动。
- 卡片之外的读回内容不进入任何持久化的"模型可见历史"结构——它们是当轮输入，不是历史重排。

## 3. 记录面（按编号寻址的投影）

### 3.1 编号 → 原文的定位

- **live 路径**：仍在模型可见历史内的编号，从上下文记忆直接取（条目原带编号）。
- **已折叠路径**：已被压缩替换出窗口的编号，经**日志折叠态投影**定位——重放折叠按与 live 相同的物化顺序镜像编号（压缩域 SlotLedger 盖章通道，ADR-007），编号 → 原始记录行的映射由折叠过程自然产出；读回服务从该投影按编号取原文。
- 一致性：live 与重放的编号一致性由压缩域既有往返闸门钉住（US5.4 家族），本域复用，不另建校验。

### 3.2 溯源字段作为导航元数据

- `context.apply_compaction` 记录的 `firstReplacedEntrySeq` / `lastReplacedEntrySeq`（被替换区间）与 `droppedEntrySeqs`（不可找回清单）是本域的**导航元数据**：
  - 目录卡片与现状卡的段结构从区间字段派生（每段 = 一次压缩的替换区间）；
  - 读回对 `droppedEntrySeqs` 命中的编号显式拒绝并如实标注（US-R1/NFR-R5）；
  - 撤销（undo）边界的编号校正沿用压缩域既有括号机制，本域不二次校正。
- 事件面 `compaction.completed` 携带的区间与丢弃计数，供卡片装配与下游呈现消费。

### 3.3 恢复语义

- 读回与检索是纯读操作，无自身恢复状态；崩溃/恢复后随会话重建自然可用。
- 卡片为投影产物：从日志重放按同一规则重建（与压缩域重放同一条折叠管线），不持有需要另行同步的第二份状态。

## 4. 卡片机制（ADR-003）

- **目录卡片**：每段旧历史一张、随压缩落位**追加**生成、永不改写——后续压缩不修改既有卡片内容。落位与省略说明消息同一先例（作为落位附属物物化进入模型可见历史，随常规记录通道持久化；可选字段追加不递增 wire 版本，沿用持久化域 ADR-008 纪律）。
- **现状卡**：全会话一张、每次整理**重写**——重写语义与压缩摘要的原位替换同类（新内容占据旧卡原位）。
- **生成时机**：挂在压缩完成事件后（自动）或经工具/命令按需——开放项 5。装配的数据来源一律为 §3.2 的区间字段（同一事实源，保证 US-R3 的"两卡同源一致"）。
- **与压缩域的边界**：压缩域负责产生编号、区间、丢弃标注与摘要本身；卡片的内容装配与维护归本域。卡片引入后压缩落位形态与既有摘要（C3）如何衔接（叠加共存 or 结构重排）**需与压缩域联合定案**——由开放项 1 的重审一并裁决，本域不单方面改写压缩落位形态。

## 5. 权限面（开放项 4 挂点）

- 硬约束（不待裁决）：读回/搜索工具必须经工具调用域统一调用校验管线——强制点在调用执行前；拦截与放行对称定义（禁用即拦且拒绝结果明确，重新启用即放行）。
- 待裁决：具体策略（自动放行，与只读内建工具同级 vs 逐次/首次用户确认）见 ROADMAP 开放项 4。

## 6. UI 呈现（下游，不在本域）

- TUI/web 对目录卡片、现状卡、读回结果的渲染，以及压缩分隔条对编号区间的展示增强，属下游呈现层：本域只保证数据面（事件面区间/计数、卡片投影、工具结果）可供消费，呈现验收归呈现层后续立项，不在本域范围。

## 7. 决策记录（ADR）

### ADR-001：寻址采用消费压缩域既有编号 + 日志只读投影，不建第二份索引性事实源

- **编号与日期**：ADR-001 · 2026-09-10
- **背景**：读回需要稳定的定位坐标与原文来源。编号已由压缩域 ADR-007 落地（会话累计、跨压缩稳定），原文已由 wire 日志完整保有——本域的定位问题已有地基，不需另造。
- **决策**：本域以 ADR-007 编号为唯一寻址坐标（消费，不重定义、不换算）；原文一律经日志折叠态投影读取；不为读回另建独立的内容存储。
- **被否决的备选**：① 按时间戳寻址——不稳定（同刻多事件）、无法进摘要指令引用；② 为读回另建摘要/内容库——违反"日志是唯一真相"，产生需同步的第二份状态；③ 按 wire 行号寻址——暴露存储细节，导入导出/换格式即作废（压缩域 ADR-007 已否决的同款）。
- **影响**：US-R1/US-R4 的寻址语义；§3 投影设计。检索**索引**（性能加速物，非事实源）另由开放项 3 裁决，不受本条约束。
- **裁决人**：用户（2026-09-10 P-E1 立项方向内含——提案口径为"原始字节本来就在日志里，不需要新存储"）。

### ADR-002：读回/搜索结果作为当轮工具结果落位（末尾追加），不重排既有历史

- **编号与日期**：ADR-002 · 2026-09-10
- **背景**：读回内容进入模型上下文有两种形态——作为当轮查询结果追加在对话末尾，或"恢复"进历史原位。前者不动任何既有字节；后者改写请求前缀（前缀缓存全部失效）、与撤销/压缩的折叠语义纠缠。
- **决策**：读回/搜索结果一律作为当轮普通工具结果落在对话末尾；历史结构零改动。
- **被否决的备选**：① 读回内容重注入历史原位——前缀缓存全失效（读一次旧账烧一整轮全价）、与撤销回退语义冲突；② 读回内容常驻上下文——窗口被旧账撑爆，与压缩的省窗目标直接冲突。
- **影响**：US-R1 验收第 2 条、NFR-R1；§2.3。
- **裁决人**：域作者（设计机制裁量，2026-09-10）。

### ADR-003：卡片采用"目录卡追加 + 现状卡重写"双卡结构

- **编号与日期**：ADR-003 · 2026-09-10
- **背景**：多次压缩下导航信息的维护有两种极端——全部重写（今日摘要的形态：每轮整理重写全部旧描述）或全部追加（只增不改）。全重写使前缀缓存逐次失效且产生"目录的目录"累积失真；全追加则卡片随压缩次数无界增长。
- **决策**：双卡结构——目录卡片每段一张、追加生成、永不改写（旧卡字节不变，缓存不失效）；现状卡全会话一张、每次整理重写（一张可变卡承载全貌，控制常驻成本）。卡片内容一律从 apply 记录的区间字段派生（§3.2），两卡同源。
- **被否决的备选**：① 单一可变目录卡——每次整理全量重写，即今日"摘要的摘要"累积缺陷的翻版；② 不落卡、全按需生成——模型冷启动不知"有什么可翻"，导航价值归零（现状卡的全貌职责不可省）。
- **影响**：US-R2/US-R3；§4；与压缩落位形态的衔接联动开放项 1。
- **裁决人**：域作者（设计机制裁量，2026-09-10）。
