# 变更记录

本页记录 Mirri Code 2.x 各版本的重要变更，更早的版本不再列出。

## 2.1.0（2026-10-22）

### 新功能

- Agent 配置文件的 `subagents` 字段改为默认拒绝：未列出 `subagents` 的配置文件无法再派发任何子 Agent。内置主 Agent 默认允许内置子 Agent，因此开箱体验不变；依赖旧「不写即全部允许」行为的自定义配置文件，需要显式列出要允许的子 Agent。

### 修复

- 修复会话中途派发的子 Agent 启动时缺少该会话已连接的 MCP 工具的问题，此前子 Agent 配置文件的 MCP 工具授权在应用重启前都无法使用。

## 2.0.1（2026-10-21）

### 修复

- 恢复各平台 CLI 与 ACP 二进制的原生发布打包，原生构建重新可以发布。
- 修复 Linux 桌面产物构建失败的问题，AppImage 与 `.deb` 安装包恢复发布。

## 2.0.0（2026-10-21）

### 新功能

- **Rust 原生内核：** CLI、桌面应用、Web UI 与 ACP 客户端背后的引擎已切换为 Rust 内核，TypeScript 内核不再接收新功能。所有客户端现在收到同一份实时事件流，包括工具进度、思考增量、压缩生命周期与后台任务事件。运行 `mirri migrate` 迁移已有会话，运行 `mirri web` 启动内置 Web UI。
- **破坏性变更：** 移除托管账号登录。`mirri login`、`mirri auth` 子命令以及 `/login`、`/logout` 斜杠命令已删除，Web UI 以供应商配置页替代登录门禁，ACP 客户端不再看到账号认证。此前通过 OAuth 配置的供应商需要显式填写 API 密钥。
- 重构会话：可在任意已完成的轮次分叉（fork），从会话日志恢复且不丢历史，压缩过程带有真实的生命周期事件。会话改为工作区感知 —— 可注册工作区、跨工作区列出与搜索会话、为新建会话选择所属工作区，并通过信任标记控制项目级 MCP 服务器与指令是否生效。
- 新增 Markdown Agent 配置文件，支持同名覆盖、启用/禁用开关，并可在 CLI 与 Web 设置中完整编辑；同时支持内置技能与按技能启用。MCP 配置改为按用户、工作区与插件分层，支持连接池实时协调、OAuth 认证与自动重连。
- 扩展供应商与模型支持：新增 Google（Gemini）与 Kimi，支持 Anthropic 提示缓存与一次性附件上传，模型解析不再静默替换你的选择。用量统计包含缓存读取与写入 token，供应商调用受超时约束，配额错误直接暴露而不是反复重试。
- web：设置扩展为覆盖供应商与模型（含目录导入）、MCP 服务器、技能、Agent 配置文件、权限规则、定时任务与后台任务。聊天区新增内联技能标签、附件磁贴、终端面板、每轮用量统计、工作区切换，以及更清晰的审批卡与提问卡。

### 修复

- 修复一批稳定性问题：正常轮次被判定为卡住、卡住后后台子 Agent 仍在运行、重新打开长会话时内存飙升、Web 会话停止后卡死、终端与事件帧丢失或重复、二进制附件上传被截断。
- 修复归档含「已开始但未结束」步骤的会话时守护进程崩溃的问题，并修复供应商流卡死导致轮次无限挂起的问题。
