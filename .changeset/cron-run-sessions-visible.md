Scheduled task runs now show up as regular sessions in the session list — visible in the sidebar with the task's title and prompt, searchable, and kept across restarts. Opening a run from the task history jumps straight to its session in the chat area like any other session, and a failed open shows a visible notice instead of silently doing nothing. Scheduled fires now deliver exactly the prompt you configured — no wrapping and no "fired" prefix on the message; schedule details stay outside the message as metadata.
