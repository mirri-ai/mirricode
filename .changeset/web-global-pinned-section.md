web: Pinned sessions now gather in one "Pinned" section at the top of the sidebar, across every workspace, with the most recently pinned session first — so the sessions that matter are all in one place instead of split into one short list per workspace. A pinned session no longer repeats inside its own workspace group, the section disappears entirely when nothing is pinned, and hovering a row tells you which workspace it belongs to. Each pinned row also carries a colored strip on its left edge plus a pushpin next to the title that opens a seven-color palette; the hover pin icon pins a session in a single click and unpins it on the next click. List search and the mobile switcher offer the same pin and unpin actions.
