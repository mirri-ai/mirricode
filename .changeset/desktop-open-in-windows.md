Add JetBrains IDEs to the desktop "Open in" menu: IntelliJ IDEA, WebStorm, PyCharm, GoLand, PhpStorm, CLion, Rider and DataGrip are now detected on both macOS and Windows, including Community Edition installs and Toolbox-managed ones. The menu also no longer omits Windows editors such as VS Code and Cursor, and File Explorer now opens the workspace folder instead of failing silently.
